Pretty Little Thing Clone

A simple, responsive front-end clone of the PrettyLittleThing fashion website.
This project was built using HTML and CSS only, focusing on layout structure, styling, and visual design.

📌 Project Overview

This project replicates key sections of the PrettyLittleThing homepage, including:

Header with search bar, logo, and navigation links

Hero image banners

Product/category sections

Promotional highlights

About section

Footer with useful links and social media

No JavaScript was used — the purpose of this build is strictly HTML/CSS layout and styling practice.

🛠️ Technologies Used

HTML5

CSS3

Font Awesome Icons

Google Fonts
